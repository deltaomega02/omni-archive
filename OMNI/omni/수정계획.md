# 고승률 트레이딩 시스템 최종 마스터 플랜

## 1. 시스템 개요

### 1.1 핵심 설계 원칙
- **목표**: 승률 60% 이상의 고승률 자동매매 시스템
- **전략**: 순수 지표 기반 + AI 의사결정
- **구조**: 3-Phase 시스템 (Phase 2 제거로 고속 실행)
- **특징**: GPT-5의 자율적 가격 설정 및 전략 수립

### 1.2 시스템 아키텍처
```
Phase 1 (Gemini 2.5 Pro): 시장 분석 + 최종 1개 코인 선정
    ↓
Phase 3 (GPT-5): 자율적 거래 전략 수립 (진입/손절/목표가)
    ↓
Phase 4: 자동 실행 및 모니터링
```

## 2. 기술적 지표 체계

### 2.1 핵심 지표 구성

#### **추세 지표 (Trend)**
- **ADX/DMI**: 추세 강도와 방향 판단의 핵심
- **이동평균선**: SMA(5,10,20,50,100,200), EMA(9,21,50,100,200)
- **특수 MA**: HMA, WMA, TEMA, KAMA
- **Supertrend**: ATR 기반 동적 추세선
- **Parabolic SAR**: 추세 반전점

#### **모멘텀 지표 (Momentum)**  
- **RSI**: 9, 14, 21 기간 + Stochastic RSI
- **MACD**: 표준(12,26,9) + 커스텀 설정
- **Stochastic**: K선, D선
- **CCI, Williams %R, ROC, TSI**

#### **변동성 지표 (Volatility)**
- **볼린저 밴드**: 1.5σ, 2.0σ, 2.5σ, 3.0σ
- **ATR**: 7, 14, 21 기간
- **켈트너 채널, 돈치안 채널**

#### **거래량 지표 (Volume)**
- **OBV**: 누적 거래량과 추세
- **VWAP**: 기관 매매 기준가
- **MFI, CMF, A/D Line**

### 2.2 다이버전스 감지 (최우선 신호)
- **RSI 다이버전스**: Regular/Hidden, Bullish/Bearish
- **MACD 다이버전스**: Line/Histogram
- **OBV 다이버전스**: 거래량-가격 괴리
- **종합 다이버전스 점수**: 강도 1-10 평가

## 3. 검증된 지표 조합 전략

### 3.1 고승률 조합 (70점 이상 진입)

#### **Golden Momentum (추세 추종)**
```
조건: MA50 > MA200 + RSI > 50 + MACD 상승 + Volume > 1.2x + ADX > 25
적용: 강한 상승 추세
가중치: 10점
```

#### **Oversold Reversal (과매도 반등)**
```
조건: RSI < 30 + BB 하단 터치 + RSI 상승 다이버전스 + Volume 급증
적용: 단기 과매도
가중치: 9점
```

#### **Breakout Momentum (돌파)**
```
조건: Donchian 상단 돌파 + BB 확대 + Volume > 2x + ADX > 30
적용: 변동성 확대
가중치: 8점
```

#### **Smart Money (기관 매집)**
```
조건: OBV 상승 + CMF > 0 + VWAP 상단 + 50 < MFI < 80
적용: 스마트머니 축적
가중치: 8점
```

### 3.2 신호 강도 계산
- **기본 점수**: 지표 조합 충족도
- **보너스**: 다중 타임프레임 일치, 다이버전스
- **최종 기준**: 70점 이상만 진입

## 4. Gemini 2.5 Pro 활용 (Phase 1)

### 4.1 분석 범위 최적화
- **분석 대상**: 상위 **20개** 코인 (100개 → 20개 축소)
- **병렬 처리**: 20개 동시 분석으로 속도 극대화
- **처리 시간**: 10-15초 목표
- **토큰 한도**: 50,000 토큰

### 4.2 Gemini 수행 업무

#### **기술적 분석**
1. 20개 코인 병렬 스캔
2. 모든 지표 계산 (40개+)
3. 다이버전스 우선 체크
4. 신호 강도 70점 이상 필터링

#### **실시간 정보 수집**
1. **뉴스 검색**
   - 24시간 내 주요 이벤트
   - 거래소 공지사항
   - 규제 변화

2. **온체인 데이터**
   - 고래 활동
   - 거래소 입출금
   - 네트워크 활동

3. **소셜 센티먼트**
   - 급등/급락 이유
   - 커뮤니티 분위기
   - 트렌드 변화

### 4.3 최종 선정 기준
```
필수 조건:
- 기술적 신호: 70점 이상
- 펀더멘털: 긍정적 or 중립
- 리스크: 관리 가능 수준
- 신뢰도: 70% 이상

선정 결과:
- 최고의 1개 코인 선정
- 또는 대기 결정 (30-120분)
```

### 4.4 대기 전략
- **대기 조건**: 적합한 코인 없음, 시장 리스크 높음
- **대기 시간**: 30분, 60분, 120분 중 선택
- **대기 메시지**: "고승률 기회를 위해 인내하며 대기"

## 5. GPT-5 자율 전략 수립 (Phase 3)

### 5.1 GPT-5의 역할
- **완전 자율적** 진입가, 손절가, 목표가 설정
- 시장 상황과 지표를 종합한 **맞춤형 전략**
- ATR 배수에 구애받지 않는 **유연한 설정**

### 5.2 GPT-5가 고려할 핵심 요소

#### **시스템 딜레이 인식**
```
프롬프트 핵심 지시사항:
"시스템 실행 딜레이(5-10초)를 고려하여 가격 설정
- 상승 추세: 현재가보다 0.2-0.3% 높게 진입
- 하락 추세: 현재가보다 0.2-0.3% 낮게 진입
- 급변동 시장: 시장가 주문 권장"
```

#### **동적 가격 설정 요소**
1. **시장 상태 분석**
   - ADX 기반 추세 강도
   - 변동성 수준 (ATR)
   - 거래량 패턴

2. **지지/저항 레벨**
   - 주요 이동평균선
   - 볼린저 밴드 레벨
   - VWAP 위치
   - 이전 고점/저점

3. **리스크-리워드 최적화**
   - 최소 1.5:1 비율 유지
   - 시장 상황별 조정
   - 승률 기반 켈리 공식
