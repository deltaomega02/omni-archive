## 📌 GCP 서버 정보
- **인스턴스**: omni-bot-server (e2-small)
- **리전**: asia-northeast3 (서울)
- **외부 IP**: YOUR_SERVER_IP
- **OS**: Ubuntu 22.04 LTS

## 🔧 초기 셋업

### 1. 기존 파일 정리 (주의!)
```bash
# .env와 requirements.txt 제외하고 모두 삭제
rm -rf !(.env|requirements.txt)
```

### 2. 가상환경 활성화
```bash
source omni-env/bin/activate
cd omni
```

### 3. 프로젝트 디렉토리 이동
```bash
cd omni
```

## ▶️ 실행 명령어

### 메인 봇 실행 (백그라운드)
```bash
nohup python3 -u main.py > output.log 2>&1 &
nohup python3 -m streamlit run dashboard/streamlit_app.py --server.port 8501 > streamlit.log 2>&1 &
tail -f output.log

```

### 대시보드 실행 (백그라운드)
```bash
nohup python3 -m streamlit run dashboard/streamlit_app.py --server.port 8501 > streamlit.log 2>&1 &
```

## 🔄 재시작 절차

### 1. 기존 프로세스 종료
```bash
# 모든 Python 프로세스 확인
ps aux | grep python

# 프로세스 종료
pkill -f "python3 -u main.py"
pkill -f "streamlit run"
```

### 2. 로그 백업 (선택)
```bash
# 날짜별 백업
mv output.log output_$(date +%Y%m%d).log
mv streamlit.log streamlit_$(date +%Y%m%d).log
```

### 3. 재시작
```bash
# 가상환경 활성화
source omni-env/bin/activate

# 메인 봇 실행
nohup python3 -u main.py > output.log 2>&1 &

# 대시보드 실행
nohup python3 -m streamlit run dashboard/streamlit_app.py --server.port 8501 > streamlit.log 2>&1 &
```

## 🐛 트러블슈팅

### 포트 충돌 시
```bash
# 8501 포트 사용 프로세스 확인
lsof -i :8501

# 포트 강제 종료
kill -9 $(lsof -t -i:8501)
```

### 로그 파일 크기 관리
```bash
# 로그 파일 크기 확인
du -sh *.log

# 로그 파일 비우기 (실행 중 유지)
> output.log
> streamlit.log
```

### 디스크 공간 확인

```bash
# 전체 디스크 사용량
df -h

# 현재 디렉토리 사용량

```

## 📝 메모
- 메인 봇과 대시보드는 독립적으로 실행 가능
- nohup 사용으로 SSH 종료 후에도 계속 실행
- 백그라운드 실행 시 `&` 필수
- `-u` 옵션으로 Python 출력 버퍼링 비활성화 (실시간 로그)
