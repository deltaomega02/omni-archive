# OMNI-XRP v8.0

**"XRP/KRW 확률 기반 자동매매 시스템"**

OMNI-XRP v8.0은 단기적인 가격 예측을 넘어, 다양한 시장 데이터를 종합하여 **'승리 확률이 높은 시점'**을 식별하고 진입하는 것을 목표로 하는 고도화된 XRP/KRW 자동매매 시스템입니다.

---

## 핵심개념 (Core Concepts)

OMNI-XRP v8.0은 세 가지 핵심 철학을 기반으로 동작합니다.

1.  **확률론적 접근 (Probabilistic Approach)**
    * 시장의 방향을 예측하는 대신, 여러 지표와 조건을 종합하여 '현재 진입하는 것이 유리한가?'를 확률적으로 평가합니다. 5.5점 만점의 체크리스트를 통해 모든 진입 시도를 계량화하고, 점수가 특정 임계값(2.5점)을 넘지 않으면 절대 진입하지 않습니다.

2.  **XRP 특화 전략 (XRP Specialization)**
    * 모든 자산에 적용되는 범용 전략이 아닌, XRP의 고유한 변동성, 패턴, 에너지 응축 현상 등을 분석하는 'XRP 전문가 시스템'을 탑재했습니다. 이를 통해 XRP 시장에서 더 정교한 의사결정을 내립니다.

3.  **자체 학습 시스템 (Self-Learning System)**
    * 모든 거래는 데이터입니다. 거래가 종료되면 시스템은 자동으로 '회고 분석'을 수행하여 성공과 실패 요인을 분석하고, 이를 '핵심 교훈'으로 정제하여 다음 거래 결정에 반영합니다. 이 과정을 통해 시스템은 시간이 지남에 따라 스스로 발전합니다.

---

## 시스템 아키텍처 및 작업 흐름 (System Architecture & Workflow)

OMNI-XRP v8.0은 **OODA 루프(Observe-Orient-Decide-Act)** 개념을 기반으로 설계되었습니다. 이는 지속적으로 시장을 관찰하고, 상황을 판단하여, 결정을 내리고, 행동하는 순환적 프로세스입니다.

#### 주요 구성 요소

* **Scheduler (스케줄러)**: `schedule` 라이브러리를 사용하여 모든 작업을 관리합니다. 핵심적인 `run_strategy_analysis_v8` (전략 분석)과 `_monitor_price_with_state_management_v8` (가격 감시) 등의 함수를 정해진 주기에 따라 실행시킵니다.
* **Core Logic (핵심 로직)**: `OMNIXRPSystemV8` 클래스에 구현된 시스템의 메인 엔진입니다. 데이터 수집, 시장 분석, 거래 실행 등 모든 핵심 기능을 담당합니다.
* **Global State Manager (전역 상태 관리자)**: 시스템의 현재 상태(`IDLE`, `ANALYZING` 등)를 관리하여 작업 충돌을 방지하고 안정성을 보장합니다.
* **Learning System (학습 시스템)**: 거래가 끝난 후 회고와 교훈 추출을 담당하며, `lessons.md` 파일을 통해 핵심 로직의 의사결정에 영향을 미칩니다.

#### 작업 흐름 다이어그램 (Workflow Diagram)

시스템은 '거래 루프'와 '학습 루프'라는 두 개의 핵심적인 순환 구조를 통해 작동합니다.

```
+---------------------+      +------------------------+      +---------------------+      +--------------------+
| 1. 관찰 (Observe)   | ---> | 2. 방향 설정 (Orient)  | ---> | 3. 결정 (Decide)    | ---> | 4. 행동 (Act)      |
|---------------------|      |------------------------|      |---------------------|      |--------------------|
| - 데이터 수집       |      | - 시장 체제 분석       |      | - 포지션 사이징     |      | - 거래 계획 저장   |
| - API 최적화        |      | - 확률론적 체크리스트  |      | - AI 전략 정교화    |      | - 매수/매도 실행   |
+---------------------+      +------------------------+      +---------^-----------+      +---------v----------+
         ^                                                               |                          |
         |                                                       (Feedback Loop)                    |
         +---------------------------------------------------------------|--------------------------+
                                                                         |
                                                            +--------------------------+
                                                            |  학습 시스템 (Learn)     |
                                                            |--------------------------|
                                                            | - 거래 종료 후 회고 분석 |
                                                            | - 교훈 추출 및 통합      |
                                                            +--------------------------+
```

#### 단계별 작업 흐름

1.  **관찰 (Observe)**:
    * 스케줄러에 의해 `run_strategy_analysis_v8` 함수가 호출됩니다.
    * `get_optimized_market_data`를 통해 API 호출을 최소화하며 시장 데이터(가격, 기술적 지표, XRP 전문가 분석 등)를 수집합니다.

2.  **방향 설정 (Orient)**:
    * 수집된 데이터를 바탕으로 `_analyze_market_regime_v8`을 통해 현재 시장이 '상승장'인지 '하락장'인지 등 거시적인 상황을 판단합니다.
    * `_validate_entry_checklist_v8`를 통해 5.5점 만점의 확률론적 체크리스트를 수행하여 현재 진입 시도의 '품질'을 점수화합니다.

3.  **결정 (Decide)**:
    * **1차 결정**: 체크리스트 점수가 **2.5점 미만**이면, AI에게 질문할 가치도 없는 기회로 판단하고 **즉시 기각**합니다.
    * **2차 결정**: 점수가 2.5점 이상이면, `_calculate_dynamic_position_size_v8`를 통해 점수에 비례하여 투자 비중을 결정합니다.
    * **최종 결정**: 결정된 투자 비중과 모든 분석 데이터, 그리고 `lessons.md`의 학습된 교훈을 OpenAI GPT 모델에게 보내 **최종적으로 정교화된 진입/목표/손절 가격**을 받습니다.

4.  **행동 (Act)**:
    * AI가 제시한 최종 전략을 `save_trade_plan_v8`을 통해 데이터베이스에 'PLANNED' 상태로 저장합니다.
    * 시스템은 4초마다 `_monitor_price_with_state_management_v8`를 통해 가격을 감시하며, 계획된 진입가에 도달하면 `_execute_buy_order_v8`를 호출하여 매수를 실행하고 상태를 'ACTIVE'로 변경합니다.

5.  **학습 (Learn)**:
    * 'ACTIVE' 상태의 거래가 목표가 또는 손절가에 도달하여 종료되면, `_perform_immediate_reflection_v8`이 자동으로 호출됩니다.
    * AI를 통해 거래의 성공/실패 요인을 분석하고(`reflection_...md`), 이 분석 결과를 기존의 교훈과 통합하여 `lessons.md` 파일을 업데이트합니다.
    * 업데이트된 `lessons.md`는 다음 **[3. 결정 (Decide)]** 단계에서 AI에게 전달되어, 시스템의 의사결정 품질을 지속적으로 향상시킵니다.

## Part 1: 시스템 초기화 및 설정 관리

안정적인 운영을 위한 기반을 설정하는 파트입니다.

* **설정 관리 (`ConfigurationManager`)**:
    * 모든 주요 시스템 변수(API 딜레이, 투자금 비율, 로깅 레벨 등)를 `config.json` 파일로 분리하여 코드 수정 없이 유연하게 설정을 변경할 수 있습니다. 파일이 없을 경우 기본값으로 자동 생성됩니다.
* **상태 관리 (`GlobalStateManager`)**:
    * 시스템의 현재 상태를 `IDLE`, `ANALYZING`, `TRADING`, `DEFENDING` 네 가지로 명확히 구분합니다. 이를 통해 '분석 중 매매 시도' 또는 '매매 중 추가 분석'과 같은 동시 작업으로 인한 충돌을 원천적으로 방지하여 시스템 안정성을 확보합니다.
* **강화된 로깅 (`EnhancedLogger`)**:
    * 단순 로그를 넘어, 어떤 함수에서 어떤 컨텍스트(예: `trade_id=123`, `price=715원`)와 함께 로그가 발생했는지 상세히 기록하여 디버깅과 성과 분석을 용이하게 합니다.

## Part 2: 데이터 수집 및 API 최적화

Upbit API를 효율적으로 사용하여 꼭 필요한 데이터만 수집합니다.

* **API 호출 최적화 (`get_optimized_market_data`)**:
    * 과거 버전처럼 1분, 5분, 15분 등 모든 시간대의 데이터를 개별적으로 요청하지 않습니다. 대신, **5분봉 데이터만 한 번 요청**한 뒤, Pandas의 `resample` 기능을 사용해 15분, 1시간, 4시간, 일봉 데이터를 메모리 내에서 가공합니다. 이 방식을 통해 **API 호출 횟수를 약 80% 감소**시키고 속도를 개선했습니다.
* **데이터베이스 설계**:
    * `trades`: 모든 거래 계획, 실행, 결과를 기록합니다. 특히 v8.0에서는 확률론적 접근을 위한 `checklist_score`, `signal_confidence_multiplier` 등과 XRP 전문가 시스템의 분석 결과(`wick_defense_result`, `energy_compression_detected`)까지 상세히 저장합니다.
    * `system_performance`: 시스템의 모든 주요 작업(전략 분석, 매수/매도 등)에 걸린 시간, API 호출 횟수 등을 기록하여 성능 병목 지점을 찾을 수 있도록 설계되었습니다.
    * `learning_data`: 회고를 통해 생성된 모든 '교훈'을 데이터베이스에 저장하고, 각 교훈이 몇 번이나 거래에 적용되었는지 추적하여 효과를 측정합니다.

## Part 3: 시장 분석 엔진

수집된 데이터를 바탕으로 시장을 다각도로 분석합니다.

### XRP 전문가 분석 (`_analyze_xrp_expert_patterns_v8`)

XRP의 고유한 특성을 분석하는 특화 모듈입니다.

* **에너지 응축 감지 (`_detect_energy_compression`)**: 일봉 볼린저 밴드의 폭이 비정상적으로 좁아지는 현상을 감지하여, 곧 큰 변동성이 발생할 확률을 계산합니다.
* **위꼬리 패턴 위험도 분석 (`_analyze_wick_patterns`)**: 최근 캔들들의 위꼬리/아래꼬리 길이를 분석하여 급격한 가격 되돌림(일명 '설거지')의 위험도를 'low', 'medium', 'high'로 평가합니다.
* **거래량 가속도 분석 (`_calculate_volume_acceleration`)**: 최근 6시간의 평균 거래량이 이전 18시간 대비 얼마나 빠르게 증가/감소하는지를 측정하여 시장의 관심도를 파악합니다.

### 종합 기술적 지표 (`_calculate_comprehensive_indicators_v8`)

다중 시간대(5분, 15분, 1시간, 4시간, 일봉)에 걸쳐 다음과 같은 핵심 지표들을 계산합니다.

* **추세 지표**: 이동평균선(SMA, EMA), MACD, 추세 강도(-3 ~ +3)
* **모멘텀 지표**: RSI, 스토캐스틱, Williams %R, CCI
* **변동성 지표**: 볼린저 밴드, ATR, 켈트너 채널, 돈치안 채널
* **거래량 지표**: OBV, VWAP, MFI, CMF

## Part 4: 거래 실행 및 위꼬리 방어 시스템

분석 결과를 바탕으로 실제 거래를 실행하고 관리합니다.

### 고도화된 위꼬리 방어 시스템 (`_activate_enhanced_wick_defense_v8`)

v8.0의 핵심 기능 중 하나로, XRP의 급격한 위꼬리/아래꼬리 패턴으로부터 포지션을 보호합니다.

1.  **손절가 도달**: 포지션이 손절가에 도달하면 즉시 매도하지 않습니다.
2.  **60초 유예 기간**: 시스템은 `DEFENDING` 상태로 전환하고 60초의 유예 기간을 부여합니다.
3.  **가격 재확인 (`_execute_enhanced_wick_defense_check_v8`)**: 60초 후 가격을 다시 확인합니다.
    * **방어 성공**: 가격이 손절가 위로 회복했다면, 이는 일시적인 '위꼬리'였다고 판단하고 포지션을 계속 유지합니다.
    * **방어 실패**: 가격이 여전히 손절가 아래에 있다면, 이는 실제 하락 추세로 판단하고 즉시 시장가로 매도하여 손실을 확정합니다.

### 트리거 기반 포지션 관리 (`_generate_position_management_advice_v8`)

포지션 보유 중에는 다음과 같은 '트리거'가 발생할 경우에만 목표가/손절가 변경을 검토합니다. 불필요한 잦은 변경을 방지하여 안정성을 높입니다.

* **수익/손실 급증**: 현재 수익률이 +15% 이상이거나 -8% 이하일 경우.
* **시장 체제 급변**: '상승장'에서 '하락장'으로 바뀌는 등 시장 상황이 근본적으로 변했을 경우.
* **XRP 전문가 경고**: 위꼬리 위험도가 'high'로 변경되거나, 에너지 응축 후 돌파가 임박했을 경우.

## Part 5: 의사결정: 확률론적 전략

모든 분석을 종합하여 최종적으로 '진입할 것인가, 말 것인가'를 결정합니다. 이 파트의 목표는 AI에게 질문하기 전에, 시스템 자체적으로 **"지금이 질문할 가치가 있는 순간인가?"**를 판단하는 것입니다.

### 5.5점 만점의 진입 체크리스트 (`_validate_entry_checklist_v8`)

신규 진입 전, 아래 6가지 항목을 점수화하여 총점을 계산합니다. **총점이 2.5점 미만일 경우, AI 분석 단계로 넘어가지 않고 즉시 기회를 기각합니다.**

1.  **시장 체제 (최대 1점)**: `_analyze_market_regime_v8`
    * **평가 기준**: 현재 시장이 명백한 상승 추세에 얼마나 가까운가?
    * **점수 로직**:
        * `명백한_상승장` + 신뢰도 `높음`: **1.0점**
        * `횡보_박스권` 또는 신뢰도 `중간`: **0.5점**
        * `명백한_하락장` 또는 신뢰도 `낮음`: **0.0점**
2.  **추세 일치성 (최대 1점)**
    * **평가 기준**: 15분, 1시간, 4시간, 일봉의 추세 방향이 모두 일치하는가?
    * **점수 로직**:
        * 주요 시간대(4개 중 3개 이상)의 추세 방향이 일치: **1.0점**
        * 절반 정도(4개 중 2개)의 추세 방향이 일치: **0.5점**
        * 추세가 혼재된 상태: **0.0점**
3.  **신호 강도 (최대 1점)**: `_count_entry_signals_v8`
    * **평가 기준**: 골든크로스, 거래량 급증, RSI 과매도 탈출 등 긍정적 기술적 신호가 얼마나 많이 발생했는가?
    * **점수 로직**:
        * 핵심 진입 신호 3개 이상 발생: **1.0점**
        * 핵심 진입 신호 2개 발생: **0.5점**
        * 신호가 1개 이하이거나 없음: **0.0점**
4.  **반대 신호 부재 (최대 1점)**: `_count_contrary_signals_v8`
    * **평가 기준**: 데드크로스, RSI 과매수, BTC 급락 등 명백한 부정적 신호가 없는가?
    * **점수 로직**:
        * 부정적 신호가 전혀 없음: **1.0점**
        * 부정적 신호 1개 발견: **0.5점**
        * 부정적 신호 2개 이상 발견: **0.0점**
5.  **손익비 (최대 1점)**: `_calculate_risk_reward_ratio_v8`
    * **평가 기준**: ATR(평균 변동폭)을 기반으로 계산한 예상 수익이 예상 손실보다 충분히 큰가?
    * **점수 로직**:
        * 예상 손익비 2.0 이상: **1.0점**
        * 예상 손익비 1.5 이상: **0.5점**
        * 예상 손익비 1.5 미만: **0.0점**
6.  **XRP 전문가 보너스 (최대 0.5점)**
    * **평가 기준**: 에너지 응축 후 돌파 가능성 등 XRP 특화 긍정 신호가 있는가?
    * **점수 로직**:
        * 에너지 응축 후 돌파 확률 80% 이상: **0.5점**
        * 에너지 응축이 감지되었거나 전문가 신뢰도 3점 이상: **0.3점**
        * 그 외: **0.0점**

### 동적 포지션 사이징 (`_calculate_dynamic_position_size_v8`)

체크리스트 총점에 따라 투자 비중을 동적으로 결정합니다.

* **A+ 등급 (4.5점 이상)**: 매우 강력한 신호. 가용 자본의 최대 90%까지 적극적으로 투자.
* **A 등급 (3.5점 이상)**: 좋은 신호. 약 70% 비중으로 투자.
* **B 등급 (2.5점 이상)**: 괜찮은 신호. 약 40% 비중으로 보수적 투자.
* **F 등급 (2.5점 미만)**: **진입 절대 금지**. 시스템은 관망 상태를 유지합니다.

### AI 기반 정교화

**체크리스트 총점이 2.5점 이상(B 등급 이상)일 경우에만** 시스템은 다음 단계로 진행합니다. 모든 분석 데이터와 현재까지 학습된 교훈(`lessons.md`)을 종합하여 OpenAI GPT 모델에게 최종적으로 정교한 진입/목표/손절 가격과 구체적인 전략을 요청합니다. 즉, **시스템이 1차적으로 확률적 우위를 검증하고, AI가 2차적으로 전략을 구체화하고 완성**하는 구조입니다.

## Part 6: 자체 학습 및 회고 시스템

거래 경험을 통해 시스템이 스스로 발전하는 핵심 파트입니다. 이 시스템의 목표는 **"같은 실수를 반복하지 않고, 성공 패턴을 강화하는 것"**입니다.

1.  **1단계: 즉시 회고 (`_perform_immediate_reflection_v8`)**
    * **언제?**: 거래가 '수익' 또는 '손실'로 종료된 직후 즉시.
    * **무엇을?**: 해당 거래의 모든 데이터를 AI에게 전송합니다.
        * **데이터**: 진입/청산 가격, 진입 당시의 체크리스트 점수 및 각 항목별 상세 내역, 시장 체제 분석 결과, 적용되었던 목표/손절가, 위꼬리 방어 시스템 작동 여부 및 결과, 최종 수익률 등.
    * **어떻게?**: AI에게 "이 거래의 **잘한 점 3가지**, **개선할 점 3가지**, 그리고 다음 거래에 **즉시 적용할 구체적인 교훈 5가지**를 추출해달라"고 요청합니다.
    * **결과물**: 개별 거래에 대한 상세한 분석이 담긴 `reflection_trade_ID.md` 파일이 생성됩니다.

2.  **2단계: 교훈 추출 및 통합 (`_extract_and_integrate_lessons_v8`)**
    * **언제?**: 새로운 회고 리포트가 생성된 직후.
    * **무엇을?**: 시스템은 **최근 10개의 회고 리포트**와 **기존의 '핵심 교훈'(`lessons.md`) 파일**을 모두 AI에게 다시 보냅니다.
    * **어떻게?**: AI에게 "이 모든 경험을 종합하여, 반복적으로 나타나는 성공/실패 패턴을 분석하고, 기존의 핵심 교훈을 **더 정교하고 체계적인 원칙으로 업데이트**해달라"고 요청합니다. 예를 들어, 'RSI가 70 이상일 때 매수해서 실패했다'는 회고가 여러 번 쌓이면, AI는 이를 '진입 원칙'에 "**RSI 70 이상에서는 추격 매수를 금지한다**'는 구체적인 규칙으로 정제하여 추가합니다.
    * **결과물**: 모든 경험이 농축된, 업데이트된 `lessons.md` 파일이 생성됩니다.

3.  **3단계: 피드백 루프 (Feedback Loop)**
    * **언제?**: 다음 신규 거래 기회를 분석할 때 (Part 5).
    * **무엇을?**: 이렇게 새롭게 업데이트된 `lessons.md` 파일의 내용 전체.
    * **어떻게?**: AI에게 새로운 전략을 요청할 때, "이것이 현재까지 우리가 배운 **'반드시 따라야 할 원칙'**이니, 이 원칙을 **절대 위반하지 않는 선에서** 새로운 전략을 수립해달라"고 지시합니다.
    * **결과**: 이 과정을 통해 시스템은 과거의 실수를 바탕으로 스스로의 행동을 교정하고, 성공적인 패턴을 다음 의사결정에 체계적으로 반영하는 **지속적인 학습 루프**를 완성합니다.
