## ArgosSystem 관리 명령어 가이드

이 가이드는 ArgosSystem의 가상 환경 설정부터 프로그램 실행 및 데이터베이스 관리까지, 핵심적인 명령어들을 안내합니다.

---

### 1. 초기 설정 및 환경 활성화

* **가상 환경 활성화**:
    ```bash
    source bitcoinenv/bin/activate
    ```
    Python 프로젝트를 위한 격리된 환경인 'bitcoinenv'를 활성화합니다. 프로그램 실행 전 반드시 수행해야 합니다.

* **프로젝트 디렉터리 이동**:
    ```bash
    cd aibitcoin
    ```
    활성화된 가상 환경에서 프로젝트의 메인 디렉터리인 'aibitcoin'으로 이동합니다.

---

### 2. 프로그램 관리

* **실행 중인 Python 프로세스 확인**:
    ```bash
    ps -ax | grep .py
    ```
    현재 시스템에서 실행 중인 모든 Python 스크립트('.py')를 확인하여, 프로그램이 제대로 실행되고 있는지 점검할 수 있습니다.

* **자동매매 프로그램 (argos.py) 수정**:
    ```bash
    rm argos.py
    vim argos.py
    ```
    기존 'argos.py' 파일을 삭제하고 'vim' 에디터를 사용하여 파일을 새로 생성하거나 수정합니다. 
    **주의: 기존 파일이 삭제되므로 중요한 내용은 미리 백업해야 합니다.**

* **실시간 매매 현황 대시보드 (argos_dashboard.py) 수정**:
    ```bash
    rm argos_dashboard.py
    vim argos_dashboard.py
    ```
    기존 'argos_dashboard.py' 파일을 삭제하고 'vim' 에디터를 사용하여 파일을 새로 생성하거나 수정합니다. 
    **주의: 기존 파일이 삭제되므로 중요한 내용은 미리 백업해야 합니다.**

---

### 3. 데이터베이스 관리

* **거래 내역 데이터베이스 제거**:
    ```bash
    rm trading_decisions.sqlite
    ```
    'trading_decisions.sqlite' 데이터베이스 파일을 삭제합니다. 
    이 작업은 **모든 기존 거래 내역을 영구적으로 삭제하므로 신중하게 수행해야 합니다.**

---

### 4. 프로그램 시작

* **자동매매 프로그램 백그라운드 실행**:
    ```bash
    nohup python3 -u main.py > output.log 2>&1 &
    ```
    'argos.py' 스크립트를 백그라운드에서 실행하고, 모든 출력(표준 출력 및 에러)을 'output.log' 파일로 리다이렉션합니다. 
    'nohup'과 '&'를 통해 터미널을 닫아도 프로그램이 계속 실행됩니다.

* **실시간 매매 현황 대시보드 백그라운드 실행**:
    ```bash
    nohup python3 -m streamlit run dashboard.py --server.port 8501 > streamlit.log 2>&1 &
    ```
    'argos_dashboard.py'를 Streamlit으로 실행하고, 웹 서비스 포트를 '8501'로 설정합니다. 
    이 역시 백그라운드에서 실행되며 모든 출력은 'streamlit.log'에 저장됩니다.
